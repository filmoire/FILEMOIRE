# Local role verification — 27 October 2026

This records local testing, not approval for a public deployment. All test accounts, stories and orders were fictional.

| Role | Verified workflows |
| --- | --- |
| Narrator | Email sign-in, story persistence, French/English draft preservation, photos/audio, manual transcripts, cover/preview, PDF/export, privacy preferences, family proposals, book approval/locking/reopening. |
| Buyer | Order details, invitation resend/cancellation, persistence after reload, narrator-controlled progress visibility and family-shared content boundaries. |
| Family editor | Shared memories only, persistent correction proposals and narrator acceptance reflected by the API. |
| Contributor | Family-shared memories only, persistent proposals and narrator rejection preserving the original. |
| Operations | MFA, metadata dashboards, orders/filtering, projects/print queue, unpublished question editing/disabling and support status/reply delivery. |
| Anonymous/unrelated accounts | Denied access to protected projects, media, PDFs, exports and administration. |

Results: **76 unit tests, 85 isolated integration tests and 80 successful live HTTP checks**. TypeScript, ESLint, diff checks and the optimized production build passed. Controlled-browser checks covered all five roles, French/English reloads and narrow layouts including a 390px viewport; this was not a complete device/browser matrix.

Fixes: persisted-English hydration mismatch; workspace titles overwritten during navigation/filtering; untranslated dialog/family/transcript labels; stale approval and reviewed-version state after reopening a book. Browser regression assertions were added. Their scenarios were manually verified in the controlled browser; the full Playwright runner was not run during this session.

Stories, uploaded files, transcripts, settings, proposals, questions and support used the real local encrypted database/storage backend. Email delivery used Mailpit. Real external email delivery, payment/refund processing, automatic transcription and supplier printing were not tested. Checkout and printing remain disabled; transcription is manual.

Temporary support access was covered by the isolated integration tests (auditing, expiry and content restrictions). No temporary support grant was created in the local application database. Temporary QA administrator configuration was removed, API sessions were revoked, and the normal local launcher was restored.
